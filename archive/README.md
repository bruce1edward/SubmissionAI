# Historical repository snapshots

`SubmissionAI/` and `SubmissonAI/` preserve the original file trees of two earlier repositories. Their original commits remain reachable through this repository's Git history. The active Continuity application at the repository root does not import these folders.

The archived knowledge bases contain text labeled with regulator and guideline names, and the archive includes a logo and generated ChromaDB files. These labels do not establish that a document is an official or current regulatory source. The original source, accuracy, and redistribution rights for each item should be checked before reuse. The root MIT license applies only to original software and authored documentation for which the copyright holder has rights; see [licensing scope](../docs/LICENSING.md).

Git commit timestamps record repository history but do not independently prove the date on which development began or establish hackathon eligibility. See [repository provenance](../docs/REPOSITORY_PROVENANCE.md).
